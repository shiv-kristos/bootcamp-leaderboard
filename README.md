## Bootcamp Leaderboard
A gamified leaderboard web app for managing and displaying trainee performance across Excelra's fresher bootcamp programs.

What it does

Public leaderboard with podium, ranked list, and category tabs
Trainee profile pages with score breakdown, streaks, attendance heatmap, and Above & Beyond log
Admin panel to manage batches, trainees, categories, scores, streaks, attendance, and Above & Beyond entries
Supports multiple batches — each batch is fully isolated
New scoring categories can be added anytime and appear on the leaderboard instantly
